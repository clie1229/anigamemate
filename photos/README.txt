[실제 사진 넣는 곳]
1) 이 폴더에 사진을 넣으세요. 파일명: <sku>-<번호>.jpg
   예) fc-smb3-1.jpg (대표), fc-smb3-2.jpg, fc-smb3-3.jpg, fc-smb3-4.jpg
2) 상위 폴더에서  python connect_photos.py  실행
3) git add -A && git commit -m "실제 사진 연결" && git push
* SKU 목록/상품명은 '사진-파일이름-가이드.md' 참고
* -1 은 카드 썸네일+갤러리 첫 컷, -2~-4 는 갤러리 추가 컷
* 일부 컷만 넣어도 됩니다(나머지는 기존 이미지 유지)
